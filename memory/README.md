# Project memory (mirrored)

These are exported from Claude Code's per-project memory store at
`~/.claude/projects/-Users-clintsanchez-Documents-Claude-Riverside-Fairways/memory/`
so they travel with the repo instead of living only on one machine.

`MEMORY.md` is the index. Each file is one durable fact — a gotcha that cost real
time, a decision worth not relitigating, or a piece of client feedback.

**The live store is the source of truth.** Re-run the copy after a session that
adds memories; editing these files does not update the store.
