```jsx
<SiteFooter phone="(225) 978-2363" email="jase@riversidefairways.com"
  serviceArea="Based in Denham Springs — serving all of Louisiana and the Mississippi Gulf Coast."
  columns={[{title:'Events',links:[{label:'Corporate'},{label:'Weddings'}]}]} />
```

Use the `ivory` logo variant here, never the green one — contrast against dark green is insufficient.
